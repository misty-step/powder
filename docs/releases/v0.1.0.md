# Powder v0.1.0

Published: 2026-07-14
Release: https://github.com/misty-step/powder/releases/tag/v0.1.0

## Release record

The first public release shipped a self-hosted agent work ledger with expiring
claims, API and CLI faces, a Docker image, and multi-architecture binaries.

The technical change list remains on the GitHub release page. Release notes are
maintained as repository documents through ordinary pull requests. Powder does
not maintain a separate marketing site or release-note service.
